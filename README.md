# وصل — بالقرآن نتّصل

منصة حلقات تحفيظ القرآن الكريم عن بُعد لـ **مدرسة جامع الصحابة لتحفيظ القرآن الكريم بحي غبيراء**.
تعمل من المتصفح مباشرة، وفكرتها مثل Google Meet.

## المزايا

- **اجتماع جديد بضغطة واحدة**: يُنشأ رمز مثل `abc-defg-hij` ورابط تشاركه مع الآخرين
- **فيديو وصوت مباشر** بين المشاركين عبر WebRTC (حتى 25 مشاركاً، مع خفض جودة الصورة تلقائياً كلما زاد العدد)
- **مشاركة الشاشة**
- **دردشة نصية** داخل الاجتماع
- **رفع اليد** و**التفاعلات** (👍 👏 😂 ❤️ 🎉 😮)
- **إبراز المتحدث** بإطار حول من يتكلم
- **شاشة تجهيز قبل الدخول** لتجربة الكاميرا والميكروفون وكتابة الاسم
- **طابور التسميع**: من يرفع يده يدخل الطابور بالترتيب، والمعلّم ينادي الطالب بضغطة فيُثبَّت في الوسط عند الجميع ويظهر له «دورك الآن»
- **التقييم بالنجوم**: بعد التسميع يختار المعلّم (ممتاز ⭐⭐⭐، جيد جداً ⭐⭐، جيد ⭐، يحتاج مراجعة)، فتظهر للطالب بطاقة احتفال مع نثار ملوّن، وتُجمع نجومه بجانب اسمه
- **غرفة ثابتة بنفس الرابط**: رابط واحد باسم مقروء (مثل `/sahaba-juz-amma`) يرسله المعلّم مرة واحدة ويدخل منه الطلاب يومياً إلى نفس الغرفة. يختار الأيام والوقت وتاريخ انتهاء اختياري، فيُضاف للتقويم كموعد متكرر مع تذكير، ويظهر في «غرفي الثابتة» في الصفحة الرئيسية
- **غرف داخل الحلقة (للمعلّم)**: يقسّم المعلّم الطلاب إلى 2–9 غرف بأسماء يختارها (توزيع عشوائي أو يدوي)، فينتقل كل طالب تلقائياً لغرفته. يستطيع المعلّم زيارة أي غرفة، وإرسال رسالة تظهر في كل الغرف، وإغلاق غرفة واحدة (فيعود طلابها للرئيسية وتبقى الأخرى) أو إغلاقها كلها. النجوم تبقى محفوظة عند التنقل
- ملخص الحضور والنجوم عند المغادرة
- **قائمة الحضور** مع حالة الميكروفون لكل واحد، والمعلّم أولاً
- **المعلّم هو منشئ الغرفة**: لا يختار أحد دوره. من ينشئ الحلقة يحصل من الخادم على «مفتاح معلّم» سرّي محفوظ في جهازه، ومن يدخل بالرابط العادي طالب تلقائياً. الخادم هو من يقرّر الدور، فلا يستطيع طالب انتحال صفة المعلّم
- **رابط المعلّم الخاص**: لفتح الغرفة كمعلّم من جهاز آخر (لا يُرسل للطلاب)
- **الأدمن (المشرفون)**: يعيّن المعلّم أي طالب «أدمن» من قائمة الحضور (زر الدرع)، فيحصل على صلاحيات إدارة الحلقة: طابور التسميع والتقييم والغرف، وأدوات الإدارة أدناه. ويمكن إلغاء الصلاحية في أي وقت
- **أدوات الإدارة (للمعلّم والأدمن)**: كتم ميكروفون طالب، إيقاف كاميرته، إنزال يده، إخراجه من الحلقة (ولا يرجع بتحديث الصفحة، ولمنع أي دخول جديد اقفل الحلقة)، كتم جميع الطلاب بضغطة، قفل الحلقة أمام القادمين الجدد، وإيقاف دردشة الطلاب. الأدمن يدير الطلاب فقط، والمعلّم يدير الجميع، ولا أحد يدير المعلّم، والخادم هو من يتحقق من الصلاحيات
- **تثبيت في الوسط**: صورة المعلّم تُثبَّت كبيرة تلقائياً عند الطلاب، ويمكن تثبيت أي شخص يدوياً، ومن يشارك شاشته يُثبَّت تلقائياً
- **اختيار الكاميرا والميكروفون** قبل الدخول وأثناء الحلقة، مع مؤشر لمستوى الصوت
- **جدولة الاجتماعات**: اختر العنوان والموعد والمدة، فتحصل على رابط ودعوة جاهزة للنسخ وزر لإضافته إلى تقويم Google أو ملف `.ics` لأي تقويم، وتظهر الاجتماعات القادمة في الصفحة الرئيسية
- **تسجيل الاجتماع**: يسجّل الصورة وأصوات جميع المشاركين ويُحفظ ملف فيديو على جهازك، ويظهر للجميع تنبيه بأن الاجتماع يُسجَّل (يعمل على Chrome وEdge في الكمبيوتر)
- واجهة عربية بالكامل (RTL) وتعمل على الجوال
- اختصارات: `Ctrl+D` للميكروفون و`Ctrl+E` للكاميرا

## التشغيل

يحتاج فقط إلى Node.js 18 أو أحدث، ولا يعتمد على أي حزم خارجية.

```bash
npm start
# ثم افتح http://localhost:3000
```

لتغيير المنفذ: `PORT=8080 npm start`

## نسخة HTML واحدة (للعرض)

```bash
npm run build
```

ينتج `dist/halaqati.html`: ملف واحد يفتح مباشرة في المتصفح بدون خادم. فيه الواجهة والجدولة والتسجيل والدخول للاجتماع بمفردك لتجربة الكاميرا والتحكم، لكن انضمام أشخاص آخرين يحتاج تشغيل الخادم.

## البنية

| الملف | الوظيفة |
|---|---|
| `server.js` | خادم HTTP يقدّم الواجهة ويعمل كخادم إشارة (Signaling) عبر Server-Sent Events |
| `public/index.html` | الصفحات: الرئيسية، التجهيز، الاجتماع، المغادرة |
| `public/app.js` | منطق WebRTC والواجهة |
| `public/styles.css` | التصميم |

الفيديو والصوت ينتقلان مباشرة بين المتصفحات (نظير لنظير)، ويقتصر دور الخادم على تبادل رسائل الاتصال الأولية.

## النشر على الإنترنت

### الطريقة الأسهل: Render (مجاناً)
1. أنشئ حساباً على [render.com](https://render.com) واربطه بحسابك في GitHub
2. اختر **New → Blueprint** ثم اختر هذا المستودع، فيقرأ ملف `render.yaml` ويجهّز كل شيء تلقائياً
3. ستحصل على رابط `https://....onrender.com` جاهز للمشاركة

### أو باستخدام Docker
```bash
docker build -t wasl .
docker run -p 3000:3000 -e WASL_SECRET=ضع-سراً-طويلاً wasl
```

مسار فحص الحالة: `/healthz`

### ملاحظات مهمة

- **HTTPS إلزامي**: المتصفحات لا تسمح بالوصول للكاميرا إلا عبر `https://` أو `localhost`.
  يمكن النشر على Render أو Railway أو Fly.io أو أي خادم خلف Nginx مع شهادة SSL.
- **خادم TURN**: بعض الشبكات (شبكات الشركات وبعض شبكات الجوال) تمنع الاتصال المباشر.
  لضمان عمل الاتصال للجميع أضف خادم TURN (مثل coturn أو خدمة مدفوعة) إلى `ICE_CONFIG` في `public/app.js`.
- الغرف محفوظة في ذاكرة الخادم، لذا شغّل نسخة واحدة من الخادم.
- **اتصال احتياطي تلقائي**: إذا حجبت الشبكة أو أحد الوسطاء قناة الأحداث (SSE) ينتقل المتصفح تلقائياً للاستطلاع الطويل (long polling) فيلتقي المشاركون في نفس الغرفة. وإذا فُتح الموقع من رابط لا يعمل عليه الخادم (موقع ثابت) تظهر رسالة توضّح ذلك.
- **TURN اختياري من الإعدادات**: أضف في متغيرات البيئة `TURN_URLS` (مفصولة بفاصلة) و`TURN_USERNAME` و`TURN_CREDENTIAL`، فتصل للمتصفحات تلقائياً دون تعديل الكود.
- **WASL_SECRET**: سرّ توقيع مفاتيح المعلّمين. ملف `render.yaml` يجعل Render يولّده تلقائياً ويبقيه ثابتاً. إن شغّلت الخادم بنفسك فاضبطه في متغيرات البيئة، وإلا تتغير مفاتيح المعلّمين عند كل إعادة تشغيل.
